# Subhendu Rana — DevOps & Platform Engineering Portfolio

A responsive, static multi-page portfolio built with HTML, CSS and JavaScript. No build tools or dependencies are required.

## Pages
- `index.html` — Home and portfolio overview
- `about.html` — Profile and engineering approach
- `skills.html` — AWS, Kubernetes/OpenShift, Terraform, Ansible, CI/CD, Apigee and operations
- `projects.html` — Sanitized high-level work highlights
- `experience.html` — Career timeline and Johannesburg onsite assignment
- `certifications.html` — Certifications listed in the supplied resume
- `contact.html` — Email, phone, LinkedIn and GitHub

## Run locally
Extract the ZIP and open `index.html` in a browser. Keep all HTML, CSS, JS, image and PDF files in the same folder.

## Publish with GitHub Pages
Upload the contents of this folder to a GitHub repository, then enable GitHub Pages from repository Settings → Pages. Use the repository root as the deployment source.

## Notes
- `profile-photo.jpg` uses the portrait supplied for this portfolio.
- `Subhendu_Rana_ATS_Resume.pdf` is provided as a downloadable resume.
- The animated skill meters are illustrative, not measured proficiency scores.
- Review public contact details before publishing. Do not upload client secrets, internal infrastructure details, or confidential project artifacts.


### Clickable technology navigation
The technology labels on the homepage are clickable. Each opens the matching skill card, where related experience, projects, and certifications can be opened directly.


Recent portfolio enhancements: homepage technology links, monitoring and alerting, Shell/Python scripting, databases and RabbitMQ, Helm, Ansible Tower, and VMware sections. CSS animations include reveal-on-scroll, portrait motion, orbit effects, hover transitions, and a blinking terminal cursor; reduced-motion preferences are respected.
